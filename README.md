# Novel Analyzer Generator GUI

This is a GUI application for analyzing the structure of novels and generating new content based on that analysis.

## Features

-   **Smart Analysis**: Deeply analyze novel structure, characters, plot, themes, etc. using LLMs.
-   **Creative Generation**: Generate high-quality derivative works that maintain the original style and narrative structure.
-   **Structural Analysis**: Outline, character, and theme analysis.
-   **Entity Management**: Replace and manage entities.
-   **RAG-Enhanced Generation**: Controllable generation with RAG.
-   **Local GUI**: A local graphical user interface.
-   **One-Click Generation**: Automate the entire process from analysis to generation.
-   **Visualization**: Visualize the entire process.

## Tech Stack

-   **GUI Framework**: PyQt6/PySide6
-   **AI Engine**: LlamaIndex
-   **Vector Database**: ChromaDB
-   **NLP Processing**: jieba, spaCy
-   **Visualization**: matplotlib, pyqtgraph
-   **LLM Integration**: OpenAI, DeepSeek, Qwen, etc.

## Installation

1.  Clone the repository.
2.  Install the dependencies: `pip install -r requirements.txt`
3.  Run the application: `python src/main.py`
